Where Network Assistant fits

Network Assistant is not a duplicate of NetPilot, RIV, or Ops Assistant. It has its own role inside Romanoti Platform: network troubleshooting, validation commands, configuration guidance, and structured technical resolution.

NetPilot

Discover

NetPilot focuses on network discovery, service visibility, candidate identification, and device awareness.

Network Assistant

Troubleshoot

Network Assistant guides symptoms, checks, commands, expected results, and troubleshooting paths.

RIV

Organize

RIV manages infrastructure context, rack information, connectivity paths, Smart Hands workflows, and lifecycle operations.

Ops Assistant

Interpret

Ops Assistant supports operational interpretation, documentation, recommendations, and report generation.

Initial troubleshooting scope

The first version should stay focused and useful: common network problems, vendor command templates, expected observations, and report-ready conclusions.

Layer 1 / 2

Interface down

Guide physical validation, port status, administrative state, cable path, optic checks, and peer-side confirmation.

  • Port status checks
  • Admin / operational state
  • Remote side validation
  • Evidence capture
Physical / Optic

CRC errors and fiber issues

Help teams review error counters, optics, light levels, cable quality, dirty fiber, and replacement recommendations.

  • CRC / input error checks
  • Optic health review
  • Fiber / transceiver notes
  • Recommended next actions
Layer 2

VLAN mismatch

Guide access/trunk validation, allowed VLANs, native VLAN, spanning-tree, and endpoint-side observations.

  • Access / trunk checks
  • Allowed VLAN review
  • Native VLAN notes
  • Port configuration summary
Services

DNS issues

Support structured DNS checks: name resolution, resolver reachability, split DNS, stale records, and service impact notes.

  • Resolver validation
  • Lookup testing
  • Record mismatch notes
  • Impact summary
Layer 3

Basic routing

Assist with route lookup, gateway checks, next-hop validation, subnet mismatch, and reachability testing.

  • Route table review
  • Gateway validation
  • Ping / traceroute checks
  • Escalation notes
Vendor Templates

Command guidance

Prepare vendor-specific command templates for Cisco, Fortinet, Juniper, Arista, Dell, and Aruba / HPE environments.

  • Show commands
  • Validation commands
  • Expected output notes
  • Report snippets
Future

BGP basics

Later versions can add BGP neighbor checks, route advertisement notes, policy review, and escalation package generation.

  • Neighbor state
  • Route advertisement review
  • Policy / prefix notes
  • Senior escalation prep
Output

Technical reports

Convert guided checks into a structured summary for handoff, escalation, client review, or internal documentation.

  • Issue summary
  • Evidence notes
  • Commands used
  • Recommended action

Proposed Network Assistant workflow

The product experience should remain simple: select the issue, select the vendor, follow guided checks, then produce a technical summary.

Select issue

Choose interface down, CRC errors, VLAN mismatch, DNS, routing, fiber / optic issue, or another guided scenario.

→

Run guided checks

Follow structured validation steps with vendor-specific command templates and expected observations.

→

Prepare report

Generate a clear technical summary with symptoms, checks performed, results, recommendations, and escalation notes.

Vendor command template direction

Network Assistant will grow around reusable troubleshooting patterns and vendor-specific command guidance for common enterprise network platforms.

Cisco

Switching and routing checks

Interface state, VLAN, trunk, counters, routing, neighbor status, and basic reachability commands.

Fortinet

Firewall validation

Interface status, routing, policy review, DNS reachability, and connectivity troubleshooting direction.

Juniper / Arista / Dell / Aruba

Multi-vendor templates

Expand troubleshooting patterns across modern network platforms while keeping the operator workflow consistent.

Future app direction

Network Assistant can later become a protected Romanoti Platform app with login access, guided troubleshooting sessions, command libraries, saved cases, and report exports.

Phase 1

Concept page

Present the product direction clearly inside Romanoti Platform and define the initial troubleshooting scope.

Phase 2

Guided issue selector

Build the first app experience around issue selection, vendor selection, guided checks, and recommended actions.

Phase 3

Command library

Add reusable command templates, expected results, evidence notes, and escalation-friendly summaries.

Phase 4

Reports and integration

Connect outputs to Ops Assistant reports, RIV context, and NetPilot discovery results where useful.

Network Assistant strengthens the troubleshooting side of Romanoti Platform.

The goal is not to replace engineers. The goal is to make troubleshooting more structured, repeatable, documented, and easier to hand off across technical teams.
